# Requirement Sign-off interface system

- Direction: calm AV commissioning worksheet; precise, trustworthy and operational.
- Domain: meeting rooms, signal paths, camera coverage, display layouts, approval states and unresolved scope.
- Color world: display glass, brushed aluminium, signal blue, status green, paper white and cable charcoal.
- Signature: a visible three-stage signal path from Answer → Review → Approve.
- Depth: borders-only, because the product behaves like a technical worksheet rather than a marketing page.
- Spacing: 4px base; 20–28px control density; 64–104px major rhythm.
- Typography: Manrope for plain-language reading; IBM Plex Mono for sequence, status and evidence labels.
- Focal pattern: the current question or requirement outcome wins through size and space; status stays quiet.
- Controls: native semantic elements first; 44px minimum hit area; visible focus and disabled states.
- Avoid: generic centered SaaS cards, decorative gradients, feature grids, excessive rounding and multiple accents.
